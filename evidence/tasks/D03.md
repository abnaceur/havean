# D03 — autocomplete and recent searches

Evidence label P: local synthetic fixtures with real isolated Docker database/API/browser services.

City-scoped community, neighborhood and district suggestions match names/aliases literally and return at most eight public records. Empty/wildcard input cannot enumerate arbitrary suggestions. The combobox debounces for 250 ms, aborts superseded requests and uses a generation guard. Keyboard arrows/Enter select a scoped location; Escape closes. Neighborhood selections use an explicit SQL-supported neighborhood filter. Optional history failure leaves browsing available.

Anonymous recent searches stay in city-keyed browser storage. Signed-in history uses session-scoped API routes and PostgreSQL row policy, deduplicates queries, caps each city at ten, and supports clear under an account/city lock. Upserts increment versions; repeat commands are idempotent. Clearing deletes only the selected account/city. Account/city changes remount the search state.

Initial browser fixture/locator assumptions were corrected before completion. Provisional screenshots show the autocomplete overlay (`evidence/d03-suggestions-{desktop,mobile}.png`).
