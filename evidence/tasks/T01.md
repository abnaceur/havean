# T01 — API-owned decimal mortgage engine

## Acceptance / minimum tests

Fifteen unit checks pass (`evidence/t01-unit.log`), including exact 120000 principal
at zero percent over 120 periods: all payments 1000.00, zero total interest and
zero closing balance, for both methods. The known 6% fixture yields first 1332.25,
final 1331.55, total interest 39869.30 and total repaid 159869.30. Integer-cent
sums reconcile principal, interest and payments. Tiny loans, fractional-cent
installments and high-value 40-year schedules never produce negative rows or grow
principal. Zero/negative term, invalid/floating money, zero principal, negative or
nonfinite rate and excessive amount/unknown fields are rejected. Initial unit run
failed dependency resolution in test-only arithmetic; integer-cent reconciliation
removed that extra import, without a new dependency.

Both existing desktop/mobile native calculator regressions pass against the new
API (`evidence/t01-browser.log`). Lint/boundaries, all types, canonical contracts,
task validation and all production builds pass (`evidence/t01-gates.log`,
`evidence/t01-build.log`). No UI/parity approval is inferred from these checks.
