# I02 scoped draft editing

Agent draft authoring can create a canonical unit and private address or reuse a permitted unit, save English property facts with decimal money, refresh and edit with versions. Owners can create/edit drafts only on their owned units; unverified new owner properties require the owner review workflow. The BFF/native forms expose loading, validation, saving and failure states. Consumer roles do not receive the draft creation button.

`evidence/draft-browser-tests.log`: four desktop/mobile agent/owner journeys passed, including persisted edits after refresh, stale 409, foreign agency denial, buyer denial and nonpublic draft projection. `evidence/final-boundary-tests.log`: terminal legacy edits return 409, an unrelated agency cannot claim the unit, and consumer creation controls are absent. `evidence/draft-types-unit-contract-tests.log`: all workspace types, 21 unit assertions and five live generated-contract assertions passed. Scoped owner reads do not request an unnecessary update lock on the canonical unit. Mobile draft screenshot is retained.
