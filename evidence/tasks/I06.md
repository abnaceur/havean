# I06 — price and status history

Status transitions and approved price changes append immutable events with actor, reason, time and exact monetary values. Price history is unique per revision; equal numeric prices do not create false events. Private history uses resource RLS. Public database projections and the history API omit actor identity, ownership evidence, proposed changes and private review notes. The consumer detail displays exact approved asking price history and public availability events.

Evidence: `evidence/revisions-integration.log` verifies one approved price event, no event after rejection, duplicate decision denial, direct anonymous denial on private history, public sentinel omission and database rejection of edits/deletions to price and status events. `evidence/revisions-browser.log` verifies the public history API/viewer, sentinel omission and idempotent HTTP decision replay on desktop and mobile. Adjacent lint/type/contract reports pass.

Retention: history survives archival for the listing lifetime; no automatic development purge. Production retention configuration and identity anonymization must preserve event amounts/order. See `docs/adr/inventory-history.md`.
