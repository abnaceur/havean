# U01 — Reference screen/state inventory

`docs/reference/screens.json` inventories 51 public/media/authenticated/operations states, with O/R/P/V evidence labels, target viewport, reference URL where available, screenshot fields, original/approved-copy flags, geometry/typography/spacing/color fields and explicit parity status. Proposed authenticated operations are labeled P. Uncaptured reference/media states remain V and blocked/unverified.

Public website capture was attempted with real Playwright at 390×844 and 375×812. Home, resale, new homes, a property detail and the official client site timed out; no access controls were bypassed. Attempts are recorded in `evidence/reference/*.json`. Limited readable-page/search-index observations are separately labeled R in `docs/reference/website-evidence.json`, including VR/video labels. No benchmark people or assets were copied into fixtures and no visual measurements were invented.

`reference-validation.mjs` validates labels, routes, viewport and existing capture file references. A screen cannot be marked verified without both screenshots, reference URL/date, measured geometry/type/spacing/colors and approved English copy. `reference.test.ts` proves missing evidence rejects a verified claim. These checks passed in the positive CI run (`evidence/ci/reference.log`, `evidence/ci/unit.log`).

Exact visual parity remains a later milestone requiring real captures and first English baseline review. This task completes the honest manifest and attempt inventory, not that visual milestone.
