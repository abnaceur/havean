# G01 — Geography hierarchy and market administration

Reviewed migrations 015/016 add stable slugs, aliases, optimistic versions and archive states; neighborhoods and transit lines/stations; city/district composite foreign keys; public-read/admin-write RLS. Database triggers refuse slug changes. Original city/district/community tables now generate UUIDs for real administrative creation.

`GeographyController` implements authenticated administrator create/read/edit/archive and versioned per-city market settings. Creation is idempotent and all mutations audit. Parent validation checks resource state and city/district consistency; database constraints independently reject cross-city transit. Public hierarchy and district endpoints expose only the selected active city. Generated typed schemas/OpenAPI cover the new operations.

`/ops/geography` implements administration with city-scoped parent selectors and market settings; tables scroll within the viewport and forms remain usable on mobile. Source and monetary market fields are explicit; no currency conversion is implied.
