# I08 — scheduled expiration and withdrawal

Implementation commit: `0b9d2b813a7dcfcf1bfcd6255b44337d3402b503`. Evidence label P: local synthetic fixtures and real Docker services.

## Acceptance

Authors/managers schedule or clear published listing deadlines with scope, optimistic version and idempotency checks. The inventory worker dispatches due jobs and invokes an inventory-owned locked database transition. The history, audit and outbox commit atomically. Duplicate deliveries produce one transition; future/rescheduled/paused jobs do nothing. Deadline text preserves PostgreSQL precision. Republishing clears inherited deadlines.

Public projections and the locked inquiry/booking destination reject due or withdrawn inventory independently of queue lag. Pause/sold/leased transitions withdraw access immediately; sale/rental completion states must match the transaction. Search removes unavailable documents from current authoritative state. No public listing cache is introduced.
