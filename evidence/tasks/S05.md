## Exact acceptance and minimum evidence

Current actual active administrator and market version are required. Country,
known ISO currency, IANA zone, units, rental period, owner-evidence requirements,
exact price presets, mortgage defaults, credential field/validity rules, market
ownership descriptions and conditional real contact/application targets are
validated. City version is required when geography changes. Atomic geography/config
updates retain exact immutable actor/time/version history. Initial historical
snapshots have explicit unavailable original actor/time. Same receipt commits once;
unknown currencies/zones, duplicate attributes, unsafe URLs, stale city/market
versions, forged administrator labels and SQL history edits deny.

Nine Docker market/recurring-charge/mortgage integrations pass. A final strengthened
S05 run passes two checks with nonempty actual charge/listing snapshots; exact
stored charges, listing prices/currencies and recorded unit areas remain original
when market currency/timezone/display unit change, then original config is restored.

real current administrator API updates. Seven real storage/scanner credential and
moderation regressions pass. New credential submissions check current policy and
retain its version. Public fields omit administrator history and private evidence.

new-city creation, invalid currency feedback, structured unit/rate/credential/tag/
contact configuration, deliberately lost save response, retained inputs and same
receipt recovery, exactly two initial/new history versions, correct actor, native
public ownership explanations and support href, absent unconfigured iOS/Android
links. Serious/critical axe violations are zero; tested viewport bounds pass.

per-square-metre prices keep explicit original basis. No record is reinterpreted.
