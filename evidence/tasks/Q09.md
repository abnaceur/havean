## Implementation

Streaming AES-256-GCM encrypts each source file with a random nonce. RSA-OAEP-SHA256 wraps the data key; Ed25519 signs the complete envelope. Recovery uses a previously trusted signing public key, verifies every encrypted/plain checksum and required file, rejects unsafe paths/links, and creates new labelled volumes without resetting originals. Quiesced capture includes native PostgreSQL base backup, archived WAL, financial and identity reconciliation hashes, realm configuration and every stored object byte. The durable WAL boundary must actually reach the archive before capture succeeds. Strict SSH/rsync off-host transfer rejects local/same-kernel destinations and verifies all remote hashes; no actual off-host target is configured or claimed.

Restore requires recovery-target promotion, native NUMERIC financial hashes and identity credential hashes. The protected application generator mounts returned volumes in a distinct HTTPS stack; only its proxy receives a gateway network. Versioning operator verifies actual S3 version IDs and byte-exact prior-version retrieval.
