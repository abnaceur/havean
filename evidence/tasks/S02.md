## Exact acceptance and minimum evidence

Six isolated Docker integration checks pass (three S02 and three S01 regressions).
Actual active platform support membership is required. Only the current assignee
or actual administrator can escalate/de-escalate, hand off, append a private note
or resolve. The original reporter can comment on an active case and reopen a
resolved case, returning it to open/unassigned. Current version and locked workflow
state serialize competing actions; same receipt replay does not append again.
Forged support/admin roles, another reporter and an old assignee cannot act.

resolution and exact status progression. A private-note sentinel is absent from
its API and SQL reads; the internalNotes field is omitted. Handoff transfers
private-note admission; immutable and standalone note insertion fail. Public
mutation payloads cannot accept private note fields. Metadata CSV uses current
staff authority and the same status/category/assignee filters, excludes subject,
description/messages/notes/files/actors and includes all matching pages. Unauthorized
exports deny, including forged roles. Bounded queue pages have 20 records.

Four final native production desktop/mobile browser journeys pass: the two existing
S01 complaint/scanned-photo/PDF journeys plus two S02 workflows. Actual staff TOTP,
native request/triage/private note/escalation/resolution, filtered URL reload,
actual CSV download and its private-text absence, reporter-safe timeline, reopening
through a deliberately lost acknowledgement and receipt retry, retained inputs,
reload, one immutable progression per committed version, subsequent reporter
comment and foreign-case/export denial all pass. Both support and reporter views
have zero serious/critical axe violations and fit configured 1440/390 widths.
Private authentication artifacts remain excluded.

An initial integration discovery failed because history SQL had an unescaped
quote; the corrected query passes. The first browser run was intentionally stopped
(exit 143) after detecting a test selector named Close instead of the existing
Close dialog control. The corrected selector passes; no application workaround.
Initial contract validation found only generated import order divergence; canonical
regeneration fixes it. Failures are retained in logs; no failed run is called green.
