# M01 — authorized conversations

Exact inquiry linkage persists source-owned resource context and customer/current
professional members. Current scope checks protect list/detail/messages and socket
upgrades/commands. Reassignment refreshes grants atomically; membership revocation
prevents subsequent access. Native inboxes expose the actual participants/category.

- `evidence/m01-integration.log`: ten checks pass (three M01, three assignment, four
  CRM). Real inquiry creation persists matching lead/resource/version and grants
  before receipt. Consumer/assigned agent can read and send. Same-agency unrelated,
