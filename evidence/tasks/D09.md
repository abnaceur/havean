# D09 — approved virtual tours and recovery

Linked panorama scenes/hotspots, approved floor-plan room mappings and the dynamically imported WebGL viewer are implemented. The listing card now displays a 360° badge only for a published, unexpired listing with an independently approved scene whose public asset is approved, scanned, decoded and dimensionally usable. Public metadata applies these same conditions, strips storage/original URLs and drops unauthorized scene targets. Media routes return BFF bytes after current permission checks; no provider redirect is issued. Migration 031 was applied to development and isolated Docker stacks.

A failed panorama no longer traps the next selected scene in its error state. Scene instances reset by ID, track actual texture-render readiness, dispose old GPU resources, and offer a functional retry. Unavailable WebGL offers an authorized image fallback. Asset/provider failures display generic text and preserve room selection and return-to-detail controls; HTTP response bodies and private provider details are not rendered. Error contrast and failed thumbnails were corrected after screenshot inspection.
