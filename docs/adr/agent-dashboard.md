# Professional agency dashboard

The dashboard composes inventory and engagement read projections into one parameterized PostgreSQL statement. Authority, totals and bounded previews therefore use the same statement snapshot and its actual database timestamp. Scope comes from active agent/manager membership in the selected agency and an active identity; supplied role claims alone cannot broaden it. Agents see their current assignments. Actual managers see the selected agency's inventory/activity, including unassigned agency inventory. Global administrator access does not turn this endpoint into global totals.

Inventory excludes sold, leased and archived records; published is a subset of that source. New leads require current `new` CRM status and professional assignment. Upcoming appointments require future start and requested/confirmed status, using their booked agent and property organization. Personally owned consumer inquiries/appointments are excluded unless professionally assigned. Each preview is bounded to five with stable ordering; totals count the entire same source. Private contact fields, messages, addresses, owner IDs, notes and financial metrics are absent.

Agency users of the older dashboard endpoint delegate to this same source. Other professional modules retain their existing separate dashboard path for their later task contracts. The agency UI replaces lease/maintenance placeholders with real inventory, publication, lead and appointment indicators, explicit definitions, current scope and UTC timestamp. Empty results show measured zero source records and empty lists. Loading/failure never synthesizes zero metrics; retry fetches the source again. While open, it refreshes every minute and offers manual refresh.

O: specification professional overview capabilities. R: supplied role/data contract. P: English local overview with explicitly synthetic fixtures, real actor sessions, exact source counts and deliberate browser failure/retry. V: original private professional interface and website parity. No public sales/ratings, benchmark performance, fresh reset or production readiness is inferred.
