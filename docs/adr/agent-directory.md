# Public agent discovery and contact

Services owns the public agent projection and canonical city/name/service-area/language filters. Names use escaped parameterized matching; district IDs belong to the active selected city, language matching is case-insensitive, and bounded pages have stable name/ID ordering. Inactive holders/memberships and other-city profiles are excluded. Public fields are whitelisted; no credential PDF/key/reference/reviewer note is returned.

Inventory exposes its read port for current public assigned offers. It applies canonical availability and current assigned-agent eligibility; private drafts and withdrawn/occupied offers cannot appear. Profile counts use that same predicate and declare the timestamp and source definition. Completed-viewing/sales/rating statistics are unavailable with an unverified flag because no independently approved public activity source exists; private CRM totals are not substituted for performance.

Consumer inquiries require explicit sharing consent, city and current profile version. Engagement calls the services destination port, which checks active identity/membership, market/service area and city-local service eligibility, then locks the selected profile until posting completes. Leads and conversations record the selected agent and actual organization. Missing consent, stale profile, other market and expired contact fail. Public email is present only as the stored consented field; withdrawal clears it through B01 authoring.

O: agent directory entry. P: local English filters/profile/pagination/contact with synthetic inventory and genuine authenticated workflow. V: benchmark detail/filter visuals and verified activity sources. No private statistics, fake reviews or original parity are claimed.
