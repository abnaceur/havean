# Public agent profiles and private credentials

Services owns profiles, credential submissions, and temporary review grants. Public biography, languages, service areas and consented email are authored independently of private holder/reference/issuer/PDF data. Agency membership, actor ownership, selected organization, profile version and active city/districts are checked on authoring. Name/city changes increment an identity snapshot and invalidate earlier verification. No legacy expiry date is converted to a credential approval.

Credential upload uses the actual private PDF pipeline: declared rights, owned immutable bytes, signature/end marker, active/encrypted PDF exclusion and ClamAV scanning. This is not a claim of structural decoding or legal authority. Submission binds its profile version/identity, current city, expiry and approved document. Independent moderator/admin decisions require current credential version/workflow and explicit review confirmation for approval. Even an administrator cannot approve or edit their own credential. Pending and approved records are unique per profile; replacements supersede earlier approval. Owners cannot erase credential history.

Public read ports derive approval from current identity, independent reviewer, city-local expiry, active holder/membership and approved private document. Expiry and revocation remove the badge immediately. Legacy dates may retain earlier service eligibility but never a verified label. Actual credential decisions update service eligibility dates. Public responses omit private credentials/document IDs/review notes. Own exports include only the holder's fields, excluding internal review notes/reviewer IDs.

Review queue access grants that reviewer 30 minutes of private evidence access. Inventory calls the services read port when authorizing the actual private download; no cross-module credential mutation occurs. Completed review revokes grants; superseded/closed records never authorize document access. Downloads remain authenticated, scoped, audited, no-store, and encrypted download tickets expire after 60 seconds.

O: agent directory entry. R: specification distinction between public profiles/private credentials. P: local onboarding/review UI, synthetic authority/document, actual actor and independent reviewer. V: licensing/legal authority, original private workflow and visual parity. No fabricated verification, ratings or credential imports.
