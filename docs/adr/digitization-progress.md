# Authenticated bounded progress streams

Dedicated Next BFF routes handle listing/intake events. They forward cookie, current organization context and Last-Event-ID, preserve a streamed body and abort on disconnect/cancel. They use a sixty-second bound; ordinary catch-all requests retain their thirty-second timeout/CSRF rules. Capture binary parts use the separately signed gateway path, not this stream or catch-all body buffering.

API validates UUID/cursor and current Identity.actor before sending headers. Every replay/poll uses a short actor transaction, rechecks persisted agency membership, target assignment/mandate and private evidence authority, then reads at most one hundred sequenced ID/state events. No OCR/source text or raw internal error is streamed. The connection expires after fifty-five seconds and instructs two-second reconnect; heartbeats are comments, not fabricated processing progress. Expired/revoked authority closes the stream and a reconnect receives the normal error. Response backpressure is bounded by connection lifetime and disconnect handling. Client cancellation aborts the upstream request; no database transaction spans a connection.

The generated OpenAPI documents text/event-stream and Last-Event-ID; generated SDK methods return a streaming Response through openEventStream instead of consuming a blob/JSON. API transactions now persist run creation/dispatch, per-attempt lease, first actual start, completion/failure, cancellation request and confirmed stop events. Renewal and receipt replay do not duplicate start events. Timeline replay includes exact lifecycle state without fabricated percent estimates. Actual processing and browser cursor/member/session revocation tests are recorded under HE-C09.
